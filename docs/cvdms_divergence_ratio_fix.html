CVDMS 发散比率检查修复

日期: 2026-05-14

关联: CVDMS C++ Backend Verification (30 keV)

1. 问题发现

现象

用户将 notebook 参数从 slice_thickness=0.1 Å 改为 0.4 Å 后，CVDMS 前向散射在 Taylor 展开的第 2 阶即溢出：

[cvdms] Using C++ CUDA backend
RuntimeWarning: CVDMS numerical overflow detected.
Exit wave shape: (31, 781, 781)

而此前在 slice_thickness=0.1 Å 下已验证通过（见 30keV 验证报告）。

2. 根因分析

2.1 Taylor 级数放大效应

CVDMS 前向散射的 Taylor 展开为：

ψ_exit = Σₙ (i·dz)ⁿ/n! · K_seriesⁿ(ψ_in)

每个 Taylor 项包含因子 dz/n。设 dz=0.4 Å 相对于 dz=0.1 Å 放大了 4 倍：

Taylor 阶数 ndz=0.1 时的 workₙdz=0.4 时的 workₙ放大倍数
n=1kseries · 0.1kseries · 0.44×
n=2K_series(work₁) · 0.05K_series(4·work₁) · 0.216×
n=3K_series(work₂) · 0.033K_series(16·work₂) · 0.13364×
n=m放大 4ᵐ 倍4ᵐ×

当 dz=0.4 且 V_max ≈ 1060 eV·Å（λ·V_max ≈ 74），K-series 内部每次迭代增长约 18.5×。Taylor 第 2 阶的 K-series 输入已经是 work₁ ≈ 2080，远超正常范围。

2.2 发散比率检查的致命缺陷

Bug: 分母包含了被检测的项本身

原代码（C++ 和 Python）的发散检查为：

exit_wave += working           // 先累加
sum_work = sum(|working|)      // 新项的和
sum_exit = sum(|exit_wave|)    // ← 包含了 working 本身！
ratio = sum_work / sum_exit    // ← 当 working 主导时，ratio ≈ 1

数学上: 因为 exit = old_exit + work，当 |work| ≫ |old_exit| 时，|exit| ≈ |work|，因此 ratio = sum(|work|)/sum(|exit|) ≈ 1。无论新项多大，ratio 永远不会超过 1！

2.3 数值验证

以 V_max=1060, dz=0.4 的单原子测试为例，Taylor n=2 时：

指标旧代码（错误）正确值
sum(|work₂|)1.64 × 10⁹1.64 × 10⁹
分母sum(|exit₂|) ≈ 1.64 × 10⁹sum(|exit₁|) ≈ 2.88 × 10⁶
ratio≈ 1.0≈ 567.8
divergence_ratio=5.0 触发?否 (1.0 < 5.0)是 (567.8 > 5.0)

旧代码的 ratio ≈ 1，永远不会触发 divergence_ratio=5.0 的截断条件。系列继续迭代直到 float32 溢出产生 NaN。

2.4 FFT 路径额外问题

FFT 路径（compute_taylor_series_fft）的 K-series 内层循环缺少停滞检测（stagnation detection）。FD 路径的 compute_k_series 在 n_above 不再减少时停止，但 FFT 路径的内联循环只检查 NaN 和完全收敛（n_above==0），没有停滞检测。这导致 FFT 路径即使修复了发散比率检查仍然溢出。

3.2 C++ 修复详情

taylor_fused_kernel（FD 和 FFT 共享）

// ---- 修复前 (旧代码) ----
if (idx < count) {
    float kr = kseries_re[idx];
    float ki = kseries_im[idx];
    float scale = dz / static_cast<float>(n);
    float wr = -ki * scale;
    float wi = kr * scale;

    work_re[idx] = wr;
    work_im[idx] = wi;
    exit_re[idx] += wr;    // ← 先修改 exit
    exit_im[idx] += wi;

    // ... NaN 检查 ...

    abs_work = sqrtf(fmaxf(mag2, 0.0f));
    abs_exit = sqrtf(fmaxf(er * er + ei * ei, 0.0f));  // ← 包含 work!
}

// ---- 修复后 (新代码) ----
if (idx < count) {
    float kr = kseries_re[idx];
    float ki = kseries_im[idx];
    float scale = dz / static_cast<float>(n);
    float wr = -ki * scale;
    float wi = kr * scale;

    // 在修改 exit 之前计算 |exit_before|
    float ebr = exit_re[idx];
    float ebi = exit_im[idx];
    abs_exit = sqrtf(fmaxf(ebr * ebr + ebi * ebi, 0.0f));  // ← exit_before

    // 然后更新
    work_re[idx] = wr;
    work_im[idx] = wi;
    exit_re[idx] = ebr + wr;
    exit_im[idx] = ebi + wi;

    // ... NaN 检查 (使用 exit_after 的值) ...
    float er = exit_re[idx];
    float ei = exit_im[idx];
    // ...

    abs_work = sqrtf(fmaxf(mag2, 0.0f));
}

FFT 路径 K-series 停滞检测

问题: FFT 路径的 K-series 内层循环缺少停滞检测。当某些像素永不收敛时 n_above 保持不变，循环应在此停滞。

// ---- 修复前 (FFT 路径 K-series 内层循环) ----
for (int inner_n = 1; inner_n <= max_inner; ++inner_n) {
    // ... FFT Laplacian + K-operator + fft_kseries_step_kernel ...
    auto ir = read_convergence(d_result, stream);
    if (ir.n_nan > 0) { inner_overflow = true; break; }
    if (ir.n_above == 0) break;
    // ❌ 没有停滞检测 — 循环可能跑到 NaN 才停止
}

// ---- 修复后 ----
int prev_inner_above = -1;
for (int inner_n = 1; inner_n <= max_inner; ++inner_n) {
    // ... FFT Laplacian + K-operator + fft_kseries_step_kernel ...
    auto ir = read_convergence(d_result, stream);
    if (ir.n_nan > 0) { inner_overflow = true; break; }
    if (ir.n_above == 0) break;
    // ✅ 停滞检测：未收敛像素数停止减少时退出
    if (prev_inner_above >= 0 && ir.n_above >= prev_inner_above)
        break;
    prev_inner_above = ir.n_above;
}

关于 V_max=10 的异常

V_max=10（弱散射）时 max|ψ| = 9e10 是已有行为（Python 路径同样如此），非本次修复引入。原因：小网格上窄高斯函数的 Laplacian 在真空中也非零，导致所有像素永不收敛（n_above=4096 恒定）。停滞检测正确截断 K-series，但仅 2 项的 K-series 不够准确，Taylor 级数需要更多项来补偿。这在真实大网格（781×781）的扩展真空中不会出现——真空像素确实会收敛。

7. 局限性与建议

dz=0.4 Å 的准确性限制

CVDMS 的二项式展开（binomial expansion）有有限的收敛半径。当 λ·V_max 较大且 dz 较大时，级数不收敛，发散比率检查会提前截断。截断后的结果虽然有限且无 NaN，但准确性降低。

建议:

  • 对 30 keV SrTiO₃ 仿真，使用 slice_thickness ≤ 0.2 Å 以获得收敛的 CVDMS 级数
  • slice_thickness = 0.1 Å 已验证通过（见 30keV 验证报告）
  • 如果必须使用 dz=0.4 Å，考虑切换到 Fourier multislice 或使用 complex128 精度（但 GPU 性能会下降）

8. 修改摘要

3 个文件，4 处修改:

  1. taylor_fused_kernel (TaylorSeries.cu:44-50) — 在修改 exit 之前从旧值计算 abs_exit，使发散比率 = sum(|work|)/sum(|exit_before|)
  2. FFT K-series #1 (TaylorSeries.cu:334-380) — 添加停滞检测 (n_above 停止减少时退出)
  3. FFT K-series #2 (TaylorSeries.cu:406-446) — 同上
  4. Python _cvdms_forward_scattering (cvdms.py:479-483) — 在 exit_wave += working 之前计算 sum_exit

修复前: 发散比率检查无效（ratio 永远 ≈1），dz=0.4 Å 时溢出

修复后: 发散比率检查正确触发，所有路径一致截断，无溢出
