CVDMS Fused Kernel 技术报告

1. 概述

本报告描述 CVDMS 算法内层 K-series 循环的 CUDA 融合核函数（fused kernel）设计与实现。

问题

原始内层 K-series 循环每次迭代需要多次全局显存读写：

for n in range(20):
    scratch = laplace(working)      # 读 working → 写 scratch
    scratch *= inv_4piK0            # 读 scratch → 写 scratch
    working *= V                    # 读 working → 写 working
    scratch += working              # 读 working+scratch → 写 scratch
    k_series += scratch * scale     # 读 scratch → 写 k_series
    working, scratch = scratch, working  # 指针交换

每次迭代约 6 次显存读写，每次 D2H 同步约 10-50 μs。20 次迭代 = ~120 次全局显存访问，带宽利用率极低。

解决方案

将整个 K-series 迭代合并为单个 CUDA kernel，每像素在寄存器中独立完成计算：

读 wave + V 从显存 → 寄存器
for n in range(iterations):
    拉普拉斯(从显存读邻域) → 寄存器
    乘系数、累加 (全在寄存器)
    写 k_series 到显存 (仅1次累加)

2. 算法细节

2.1 K-operator

\[ K(\psi) = V \cdot \psi + \frac{\nabla^2(\psi)}{4\pi K_0} \]

其中 K0 = 1/λ，λ 为电子波长。

2.2 K-series

\[ \text{K-series}(\psi) = \sum_{n=1}^{N} c_n \cdot K^n(\psi) \]

系数：

  • c1 = 1
  • $c_n = \frac{(1.5 - n) \cdot 4 \cdot \text{inv\_4piK0}}{n}$ for n > 1

2.3 有限差分 Laplacian (可分离, 8 阶精度)

\[ \nabla^2(\psi)[i,j] = \text{prefactor} \cdot \sum_{k=-n}^{n} c_k \cdot (\psi[i+k,j] + \psi[i,j+k]) \]

周期边界条件通过模运算实现：(row + k + H) % H。

2.4 收敛检测

每像素独立计算 $|c_n \cdot K^n(\psi)| > \text{threshold}$，通过 block-level shared memory atomic counter 汇总。仅单 int D2H 同步/迭代（vs 原版每 2 迭代一次 D2H + 浮点规约）。

4. CUDA 编译器 Bug 及解决方案

问题

CuPy 13.6.0 中，将 lap_factor 和 inv_4piK0 作为 CUDA kernel 函数参数传入时，sum * lap_factor 被编译器优化为 0。

// 错误：lap_factor 作为函数参数传入时乘积被优化为 0
void kernel(..., float lap_factor, ...) {
    float result = sum * lap_factor;  // → 0
}

诊断

通过增量构建 kernel 逐步定位：

  1. v1（无参基准）：正确
  2. v2 (+ shared memory)：正确
  3. v3 (+ base/stride)：正确
  4. v4 (+ K-operator params)：失败（乘积归零）
  5. v5 (+ __restrict__)：失败

确定是 CUDA 编译器对函数参数的浮点乘法触发了错误优化。

解决

将常量作为编译期字面量嵌入 CUDA 源码，而非通过函数参数传递：

# Python 端：用字面量替换占位符
kernel_src = kernel_src.replace("__LAPF__", f"{lap_factor}")
kernel_src = kernel_src.replace("__INV4PIK0__", f"{inv_4piK0}")

# CUDA 端：编译时常量
const float lap_factor = __LAPF__f;   // → const float lap_factor = 0.19894368f;
const float inv_4piK0 = __INV4PIK0__f;

注意：不同物理参数（wavelength, dx, dy）会生成不同的 kernel 实例，通过 cache key f"k_iteration_fused_{lap_factor}_{inv_4piK0}" 区分。

6. 与原始算法的差异

收敛检测

原始算法每 check_interval=2 次迭代做一次全局收敛检查。Fused kernel 每次迭代都做逐像素收敛检查，精度更细但行为略有不同。

浮点精度

Fused kernel 使用 32-bit 浮点运算，与原始算法的计算顺序不同可能导致 1e-4 ~ 1e-7 级别的数值差异（取决于比较基准）。

本报告及代码中，必须区分两个易混淆的概念：

  backscatter  = BSC_correction(ψ)     ← 背散射修正(场)
  exit_wave    = pure_forward - backscatter  ← 修正后的前向波

累积阶段:
  bsc_wave_conj = back_propagate(all backscatter fields)  ← 背散射波

11.2 关键发现

  1. 30 keV 差异远大于 300 keV: NCC 从 0.996 降至 0.866，max|diff| 从 0.86 增至 2.18。 根本原因是低能下散射更强，combined K-operator 中 V 与 ∇2 的非对易性 更显著，CVDMS 和 Fourier split-step 在数学框架上的差别被放大。

  2. FFT Laplacian 无 AA → nan: 无反混叠时 k-space Laplacian 计算 -k²·FFT(ψ)， k_max 处 k² 巨大（~104 Å−2），高频分量在 K-operator Taylor 级数中被放大 至超出 float32 范围（~3.4×1038）→ 溢出为 inf → 后续运算产生 nan。 这确认了 FFT Laplacian 必须配反混叠孔径。

  3. GPU 内存约束: 30 keV 波长约 0.07 Å（vs 300 keV 的 0.02 Å），散射角约 3.5× 更大， 需要更细采样。采样从 0.1 Å/pixel 降至 0.03 Å/pixel，像素数增加 ~10×， 对 GPU 内存（RTX 3070 8 GB）造成压力。可通过 _cleanup_gpu() 在 heavy cell 间管理。

  4. max_terms 和 convergence_threshold 仍无影响: Taylor 级数在默认 50 项已收敛， 增加至 200 项或降低阈值至 1e-10 不改变结果。

⚐ CVDMS+BSC I/I0 > 1（非物理）根因分析：

CVDMS+BSC 的总强度始终 > 入射强度（+0.5%），是被动系统不应出现的非物理增益。 问题源头定位在 cvdms.py:213 的相干场减法：

exit_wave = pure_forward - backscatter    # cvdms_multislice_step, line 213

数学机制：BSC 修正后的强度为

\[ |ψ - \text{bsc}|^2 = |ψ|^2 + |\text{bsc}|^2 - 2\,\text{Re}(ψ \cdot \overline{\text{bsc}}) \]

当 bsc 与 ψ 的相位差为 π（反相）时，干涉项为正： |ψ-bsc|² = (|ψ|+|bsc|)² > |ψ|² → 强度净增益。物理上要求 bsc 与 ψ 同相 （干涉项为负，BSC 带走能量），但算法未保证此相位关系。

电压依赖：BSC 的计算公式 (cvdms.py:801)

backscatter = (raw_diff + correction) / (2*K0)    // K0 = 1/λ
  • 30 keV: λ ≈ 0.07 Å → K0 ≈ 14.3 Å−1 → 1/(2K0) ≈ 0.035
  • 300 keV: λ ≈ 0.02 Å → K0 ≈ 51.2 Å−1 → 1/(2K0) ≈ 0.010

BSC 振幅在 30 keV 下约为 300 keV 的 3.5×，使得相位误差效应被放大到可观测水平。

三个误差来源（叠加效应）：

  1. 细采样下的高频放大（新发现，主因）: 细采样 → 波函数包含更多高频分量 → K-operator（V·ψ + ∇2ψ/(4πK0)） 对高频分量作用更强 → Taylor/K-series 截断误差增大。 两种 Laplacian (FD 和 FFT) 表现一致，证明与 Laplacian 实现无关。

  2. float32 精度损失 (cvdms.py:776-777):

    backscatter = wave_2;  backscatter -= wave_1

    wave_1 和 wave_2 都包含主导项 K0*ψ（~14×|ψ|），两者相减得 raw_diff 编码相邻层势函数差。两个大数相减在 float32 下精度损失显著，系统性地 影响 BSC 的相位分布。

  3. 1/k 修正级数 (cvdms.py:797-838): 公式使用 $(1 + K/(\pi K_0))^{-1/2}$ 的二项式展开，使用逐像素收敛循环 （n_above = sum(|scratch| > threshold) + 停滞检测）而非固定截断阶数。 30 keV 下 K/(πK0) 较大。增大 max_inner 对 I/I0 无改善（见下方 order 测试表）， 说明二项式展开本身已收敛。

  4. 无后处理强度归一化: BSC 路径中无任何 sum(|ψ|²) 守恒约束， 完全依赖算子展开的数学正确性来保持幺正。

11.4 I/I0 > 1 根因分析

30 keV 下 CVDMS+BSC 的 I/I0 > 1 是算法近似而非数值 bug，涉及 SBA 框架、 前向传播器与 BSC 之间的误差耦合、以及 K 级数差分运算的数值条件数三个层面。

11.4.1 SBA 框架的非幺正性

单背散射近似（SBA）的核心假设是背散射波远弱于前向波，因此采用微扰处理：

\[ \psi_{\text{total}} = \psi_{\text{forward}} + \varepsilon \cdot \psi_{\text{backward}} + O(\varepsilon^2) \]

SBA 在此做了一次截断：忽略 ψbackward 对 ψforward 的反馈（即多次背散射）。 这个截断破坏了幺正性——完整的多片层散射是幺正的（概率守恒），但 SBA 等价于从耦合波方程中删除了反向耦合项，使得概率不再严格守恒。

I/I0 > 1 的直接原因：在 SBA 框架下，背散射修正项 B(ψ) 是从前向波中 减去一个"背散射损失"，但这个减法的幅度和相位由近似算子决定，不保证 |ψ - B(ψ)| ≤ |ψ|。当背散射项的振幅过估计或相位偏差超过 90° 时， 强度反而增加。

11.4.2 前向传播器误差与 BSC 误差的耦合

这是最关键的间接机制。前向 CVDMS 传播器本身有截断误差 εT：

\[ \psi_{\text{forward}} = \psi_{\text{exact}} + \varepsilon_T \cdot \psi_{\text{err}} + O(\varepsilon_T^2) \]

其中 εT 来自泰勒级数有限项截断（conv_thresh=1e-6 控制，但不为零）。

BSC 算子作用在前向波上产生差异：

\[ \begin{aligned} B(\psi_{\text{forward}}) &= B(\psi_{\text{exact}} + \varepsilon_T \cdot \psi_{\text{err}}) \\ &= B(\psi_{\text{exact}}) + \varepsilon_T \cdot B(\psi_{\text{err}}) + O(\varepsilon_T^2) \end{aligned} \]

误差项 εT·B(ψerr) 在以下条件下不可忽略：

  1. BSC 算子放大高频成分（拉普拉斯项 ∇2/(4πK0) 在精细采样下放大）
  2. 前向误差 ψerr 恰好落在 BSC 高响应的频率区间
  3. 修正后 exit_wave = ψforward − B(ψforward)，误差项叠加而非抵消

在 30 keV + 0.03 Å 条件下，三点同时成立：

  • K0 = 14.3 Å−1 → kcritical = 2.17 Å−1，BSC 放大倍率 = O(k2/K02) ≈ 10
  • 前向泰勒截断误差集中在高频（拉普拉斯算子的收敛慢于势能项）
  • B(ψerr) 与前向波 ψexact 的相位关系使得 ψforward - B(ψforward) 的模长 > |ψforward|，出现非物理增益

11.4.3 K 级数差分运算的条件数灾难

BSC 的核心操作是两个相邻片层 K 级数的差分：

\[ B(\psi) = \frac{K_j - K_{j-1}}{2 K_j} \cdot \psi \]

在 ∂z → 0 的极限下，Kj ≈ Kj−1，差分变为两个接近相等的数值相减。 设 S = Kj 在数值上的值，ΔS = Kj − Kj−1，则差分的条件数：

\[ \kappa \approx \frac{\|S\|}{\|\Delta S\|} \times |\text{forward\_error\_amplification}| \]

对 SrTiO3 30 keV、采样 0.03 Å：

参数值
Kj 典型模长~106 (级数中间项)
|ΔS| 典型值~103 (相邻片层差异)
条件数 κ~2000
float32 精度~1.2 × 10−7
有效精度损失~log10(2000) ≈ 3.3 位十进制

结果：float32 的 7 位有效数字中损失约 3 位，仅剩 ~4 位可靠。 这解释了为什么改用 complex128（15 位有效数字）后 I/I0 趋于 1。

11.4.4 电压依赖性与采样耦合

I/I0 > 1 问题并非某一电压所独有——所有电压下均可出现，取决于采样精细程度。 问题由电压和采样共同决定：

电压效应：BSC 算子幅值与 K0 成反比，低电压的 BSC 修正更大。

采样效应：条件数 κ ∝ 1/|ΔS|，而 |ΔS| 随采样变细而减小（相邻片层差异变小）。 精细采样同时提高 Nyquist 频率，允许更多高频成分进入 K 级数，进一步增大 κ。

因此，不同电压只是"触发阈值"不同：

电压K0 (Å−1)B 相对幅值临界采样（出现 I/I0 > 1）
300 keV50.791.0× (基准)≤ 0.03 Å 时出现
80 keV24.932.0×≤ 0.05 Å 时出现
30 keV14.303.5×≤ 0.10 Å 时出现
10 keV8.176.2×≤ 0.15 Å 时出现

300 keV 在常规采样（≥ 0.1 Å）下无问题，是因为 BSC 修正幅值小，条件数 κ 在 float32 容忍范围内。但当采样加密到 0.03 Å 时，相邻片层差异 ΔS 减小， 条件数 κ 增大到同样触发 I/I0 > 1。这是一个量变而非质变——所有电压在足够 精细的采样下都会出现强度不守恒，仅是触发采样阈值不同。

11.4.5 强度单调递减失败的机制

物理上弹性散射的透射束强度应随厚度单调递减（量子力学概率流守恒）。 实测 CVDMS+BSC 在 30 keV + 细采样下 I/I0 呈波动，根因如下：

  1. BSC 修正过度：在特定片层，背散射项 B(ψ) 与前向波 ψ 反相位叠加， 导致 |ψ - B(ψ)| > |ψ|
  2. 误差随片层积累：前向 CVDMS 的泰勒截断误差在每片层有系统性方向（非随机）， 跨片层积累后与 BSC 修正产生共振
  3. SBA 反馈缺失：真实物理中背散射损失的能量应在前向波中体现为衰减， 但 SBA 的单向近似使得修正项在特定条件下"反向馈入"前向通道

结论：

  1. CBED 在 30 keV 下的自洽性显著优于同采样率的 HRTEM，因为汇聚探针 限制了高频分量，减轻了 K-operator 放大效应
  2. ct=1e-6 是 CBED 的合理默认值——更严格的阈值反而累积 Taylor 截断误差
  3. 单冷冻声子态可将 max excess 从 +1.44% 降至 +0.22%，改善效果优于 HRTEM （+0.575% → +0.515%），因为 CBED 中探针-晶体相位关系更敏感
  4. BSC 检查受 GPU 内存和 float32 精度双重限制，B2 的 FAIL 不代表算法错误

13.1 核心结论

abTEM CVDMS 与 ImageSimulation_CGS CVDMS 在算法层面完全等价：

  • 外层 Taylor 展开: exp(i·dz·K) = Σ (i·dz)&supn;/n! · Kn(ψ0) — 完全一致
  • 内层 K-series: Σ cn · Kn(ψ) with c1=1, cn=(0.5-n+1)·λ/(π·n) — 完全一致
  • K-operator: K(ψ) = V·ψ + ∇2ψ/(4πK0) — 完全一致
  • FD 8 阶 9 点模板: f0=1.6, f1=-0.2, f2=8/315, f3=-1/560 — 机器精度一致
  • BSC 算符: (kj - kj-1)·ψ/(2K0) · (1+K/(πK0))-1/2 — 完全一致
  • 1/k 修正级数: Σ binom(-1/2,n)/(πK0)n · Kn — 完全一致
