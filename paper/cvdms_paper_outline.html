A Convergent Series Solution to the Multiple Electron Scattering Problem: The Chen-Van Dyck Multislice Algorithm

Target: Communications Physics Nature Portfolio · IF 5.8 · 中科院 1区 Top · Gold OA

Backup: Computer Physics Communications (2区, IF 3.4) · Physical Review B (2区Top, IF 3.7)

投稿策略: Communications Physics → CPC → PRB

1. Abstract

提出 CVDMS（Chen-Van Dyck Multislice）算法，一种基于双 Taylor 级数展开的透射电子显微镜多层法。该算法以像素级精度求解含投影势和 Laplacian 算符的 K 算子 K(ψ) = σ·V_proj·ψ + ∇²ψ/(4πK0)，其中外层指数展开 exp(i·Δ·K) 捕捉厚层传播，内层平方根展开 Σ cn·Kⁿ 构建 K 级数。CVDMS 的 全物理收敛性由散射平均自由程决定——当 σ·V 项主导 ∇²/(4πK0) 时级数发散，该临界点恰对应多重散射的物理极限——将数值稳定性约束转化为对电子散射固有物理的描述。算法集成了三项关键技术：(1) 像素级收敛控制（发散比 + 停滞检测），(2) 逐次 FFT 抗混叠滤波，(3) 通量守恒 Fresnel 背散射校正。通过五组自验证和与实验的定量对比验证了该方法的正确性。

2. Introduction

物理问题: 高能电子在凝聚态物质中的多重散射是一个量子力学多体问题。尽管 Schrödinger 方程在理论上完备，但在 TEM 能量（80-300 keV）下求解面临着入射波长远小于原子间距的极端多尺度挑战。

现有方法的局限: 传统 FFT 多层法通过将样品离散为薄片并在倒空间执行 Fresnel 传播，依赖薄层近似（dz → 0）。Bethe 本征值方法在倒空间求解 Bloch 波，计算量随束斑尺寸迅速增长。两种方法的精度受制于采样厚度和截断阶数，且缺乏像素级的误差控制。

CVDMS 的提出: Chen-Van Dyck Multislice 将传播算符精确分解为指数展开与平方根展开的双级数形式，使每一切片的计算精度可独立控制。级数的收敛行为与物理散射过程直接对应——当势场足够强时收敛自然终止于散射平均自由程——这赋予了算法内在的物理自洽性。

3. Theory

3.1 Multislice 算符与 K-算子

多层法的核心是将样品沿 z 方向分割为厚度 Δ 的薄层，每层内将势场视为投影势 V_proj(x, y)。从层 j 到层 j+1 的传播写为:

ψ(x, y, z+Δ) = exp(i·K·Δ) · ψ(x, y, z)

其中 K-算符（Kinetic + Kernel 算符）定义为:

K(ψ) = σ · V_proj · ψ + ∇²ψ / (4π K0)

这里 σ = 2π/λ·(E+E0)/(E+2E0) 为相互作用常数，K0 = 1/λ 为真空波数。

3.2 双 Taylor 级数展开

外层展开（指数展开）: 传播算符 exp(i·K·Δ) 关于 K 展开为 Taylor 级数:

exp(i·K·Δ) = Σn=0 (i·Δ·K)ⁿ/n!

内层展开（平方根展开）: K-算子本身通过平方根级数展开为 Kⁿ 的组合，系数 cn 源自 K-谱半径的倒数:

c1 = 1,   cn = (0.5 − n + 1) · λ / (π·n)   (n > 1)

双级数结构使算法能自适应调节每层内的迭代次数，实现像素级的精度控制。

3.3 物理收敛性分析

CVDMS 的收敛性由 K-算子的两大组成部分的相对强度决定。Laplacian 项 ∇²/(4πK₀) 携带比例系数 1/(4πK₀) = λ/(4π²)，对于 30 keV 电子约为 4.5×10⁻⁴ Å — 这是一个本质性的小量。潜在项 σ·V 在一个典型的含 SrTiO₃ 切片的数量级约为 0.1–1.0 Å⁻¹。因此:

  • 在低势区域（真空或轻原子间隙），Laplacian 主导，∇²项 ~ k²，K-级数衰减缓慢但可控
  • 在高势区域（重原子列），σ·V 项主导，K-级数迅速衰减
  • 发散临界点对应于散射平均自由程 lmfp = 1/(σ·Vrms)，直接提供了物理可解释的收敛边界

3.4 Fresnel 背散射校正

传统 SBA（Single Backscattering Approximation）公式 B = Δk/(2knext) 违反幺正性——当 kcur > knext 时 |1 − B|² > 1。CVDMS 采用通量守恒 Fresnel 反射公式:

R = (kcur − knext) / (kcur + knext),   T = √(1 − |R|²)

ψout = T · ψin   ⇒   |ψout|² = (1 − |R|²) · |ψin|² < |ψin|²

4. Implementation

4.1 像素级收敛控制

每个像素独立跟踪 K-级数项的大小 |term|。当对于某个像素 |term| < threshold 时，该像素标记为收敛；薄层计算在所有像素收敛后终止。

4.2 发散比与停滞检测

发散比 r = Σ|work| / Σ|exit_before|。当 r > divergence_ratio 时系列截断。停滞检测：当未收敛像素数不再减少时终止。

4.3 逐次 FFT 抗混叠滤波

势乘法 V·ψ 将波函数带宽加倍（频域卷积），产生高于 Nyquist 的频率分量，这些分量经 Laplacian ∇²ψ 放大 ~k² 后导致数值溢出。CVDMS 在每次 K-算子应用后施加 FFT 带限滤波（2/3 Nyquist 余弦锥形孔径），在保持精度的同时消除混叠放大。

4.4 CUDA 实现

为适应 STEM 实时仿真需求，算法使用 CUDA 在单块 GPU 上高效执行: 有限差分 Laplacian 以共享内存分块（32×16 tile）实现；cuFFT 路径对大规模网格提供精确带限 Laplacian；多流并发处理 batch；单次 D2H 拷贝完成所有像素的收敛判定。

5. Results

5.1 Self-Verification（自验证）

Phase 0 — 最高优先级：必须全部通过后方可进入 §5.2

V1: 通量守恒 / 幺正性

在真空（V=0）中，K = ∇²/(4πK₀)，exp(i·K·Δ) 应为纯相位传播：|ψexit|² = |ψin|²。预期：对各采样厚度，通量守恒误差 < 10⁻¹⁴。

V2: 真空 Fresnel 解析极限

真空中的平面波入射应与解析 Fresnel 传播公式的卷积核对齐。预期：薄层级联的 CVDMS 与 FFT 传播完全一致。

V3: dz 自洽性

对同一总厚度 t，将样品分割为不同切片数（如 50 层 vs 100 层）施加 CVDMS。预期：收敛后的退出波振幅与相位在 < 0.1% 精度内一致。

V4: 阈值收敛性

对不同 convergence_threshold（10⁻⁶, 10⁻⁸, 10⁻¹⁰），验证积累到收敛的总项数量呈对数增长，退出波变化量随阈值递减。

V5: 实现一致性

在相同输入条件下确保 C++ CUDA 后端与 Python fused kernel 后端产生等效结果（相对 L2 范数 < 10⁻⁵）。

6. Discussion

通过与相位多层法和 FFT 多层法的对比分析 CVDMS 计算精度的系统优势。讨论像素级收敛检测对避免过计算的效能。阐明 Fresnel BSC 公式不仅恢复了幺正性，而且物理上等价于介电界面反射的量子力学处理，作为 SBA 的自然推广。最后将 K-级数的临界发散点与散射平均自由程对应，展示 CVDMS 收敛行为如何反映电子散射的物理极限。

7. Conclusion

CVDMS 为透射电子显微镜的多重散射问题提供了一个收敛可控的级数解。双 Taylor 级数结构与物理散射过程的内在对应使该方法在精度、收敛性和可解释性方面均具有优势。面向未来，CVDMS 可推广至非弹性散射和声子散射。C++/CUDA 实现兼容主流 TEM 仿真工作流，且易于与基于 abTEM/Py4DSTEM 的自动化分析框架集成。
